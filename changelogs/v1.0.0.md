# v1.0.0

- Port the AetherNexus C++/WinUI workspace to an AstrBot Star plugin and a Fluent-inspired plugin view.
- Preserve Dashboard, Playground, BUILD, MANAGE and local migration workflows through public APIs and local version-1 documents.
- Replace desktop navigation with the workspace sidebar; all original entries retain their names. See [the entry-point mapping](../docs/en/usage.md).
- Replace Windows credential persistence with server environment variables or process-memory slots; use local SQLite only for non-secret preferences and prompt revisions.
- Replace microphone capture with uploaded audio in the restricted iframe; enforce 25 MiB upload and 40 MiB response limits.
- Include isolated HTTP/WebSocket contracts, real AstrBot public-API lifecycle tests, and real-bridge browser smoke checks. No live OpenAI account acceptance tests were performed.
